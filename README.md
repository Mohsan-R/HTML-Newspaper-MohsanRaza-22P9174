## Project Description

This project recreates a pre-1990 Urdu newspaper front page layout using only HTML and inline CSS.  
The layout includes a masthead headline, sidebar column, multi-column articles, and newspaper-style formatting.

---

## Features Implemented

- Semantic HTML5 tags (`header`, `nav`, `section`, `article`, `footer`)
- Table-based layout structure for accurate newspaper columns
- Multi-column text formatting using `column-count`
- Three images included (leader photo, article image, newspaper logo)
- Proper heading hierarchy (`h1`, `h2`)
- List element included in sidebar
- Inline styling only (no external CSS or JavaScript)
- Comments added for readability and viva explanation

---

## Challenges Faced

The biggest challenge was recreating the traditional newspaper column structure using only HTML without external CSS files.  
This was solved by using tables for layout and CSS column properties for newspaper-style text flow.
